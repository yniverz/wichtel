:::tip[Auf einen Blick]

- **Schichtplan:** _Schichten_ → optional Bereich wählen → _Schichtplan drucken_.
- **Helferliste einer Schicht:** Schicht öffnen → _Helferliste drucken_.
- Auf der Druckansicht oben _Drucken_ tippen (oder als PDF speichern).
- Jede Liste hat eine Spalte _Da_ zum Abhaken auf Papier.

:::

## Schichtplan

1. Öffne _Schichten_.
2. Wähle oben einen Bereich, wenn du nur diesen (mit seinen Unterbereichen) drucken willst. Ohne
   Auswahl kommen alle Schichten deiner Bereiche.
3. Tippe auf _Schichtplan drucken_.
4. Prüf die Vorschau und tippe oben auf _Drucken_.

Der Plan hat die Überschrift _Schichtplan_ (mit Bereichsname, wenn du einen gewählt hast). Jeder Tag
beginnt auf einem neuen Blatt; eine Schicht wird nicht über zwei Seiten getrennt.

## Helferliste einer Schicht

1. Öffne die Schicht.
2. Tippe oben auf _Helferliste drucken_.
3. Tippe auf _Drucken_.

## Was auf dem Papier steht

Für jede Schicht:

- Tag, Uhrzeit, Titel und der Bereich (mit übergeordneten Bereichen),
- _Treffpunkt_ und _Ansprechperson_, wenn eingetragen,
- eine Tabelle mit _Position_, _Name_, _Telefon_ und _Da_.

Pro Position gibt es so viele Zeilen wie Plätze. Freie Plätze bleiben als leere Zeilen stehen – dort
kannst du spontane Helfende von Hand eintragen. Die Namen stehen als „Nachname, Vorname“,
alphabetisch. Plätze, die jemand für seine Gruppe reserviert hat, sind mit „(reserviert)“ markiert.
Anfragen und Wartelisten stehen nicht auf der Liste.

Die Spalte _Telefon_ ist nur gefüllt, wenn deine Rolle _Kontaktdaten der Helfenden sehen_ im Bereich
der Schicht hat.

## Häufige Fragen

### Kann ich nur einen Tag drucken?

In der Oberfläche gibt es dafür keine Auswahl. Weil jeder Tag auf einem neuen Blatt beginnt, kannst du
im Druckdialog einfach nur die Seiten dieses Tages wählen.

### Wie komme ich zurück?

Oben links auf der Druckansicht steht _← Zurück_.

### Übertrage ich die Haken später in Wichtel?

Ja, die Papierliste ist nur eine Hilfe. Punkte gibt es erst, wenn die Anwesenheit in Wichtel
abgehakt ist (siehe [Besetzung](/wichtel/leads/staffing/)).

## Sonderfälle

<details>
<summary>Die Druckansicht ist hell, obwohl ich den Dunkelmodus nutze</summary>

Das ist Absicht: Die Druckansicht sieht immer aus wie Papier (A4).

</details>
