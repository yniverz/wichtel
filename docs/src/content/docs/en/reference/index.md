This is what you need to look things up rather than follow step by step.

## In this section

- **[Glossary](/wichtel/en/reference/glossary/)** – every term in the app, from _Admin_ to _Your code_,
  each explained briefly with a link to the detailed page.
- **[Features](/wichtel/en/reference/features/)** – the complete list of what Wichtel can do, sorted
  by volunteers, leads and organisers.
- **[Permissions](/wichtel/en/reference/permissions/)** – every permission a role can contain, what it
  allows and what only admins can do.

### Contributing

- **[Development](/wichtel/en/reference/development/)** – running Wichtel locally, commands, code
  structure, guidelines and how to edit this help site.
- **[Concept](/wichtel/en/reference/concept/)** – the original domain planning and its rationale.
- **[Design guidelines](/wichtel/en/reference/design/)** – how Wichtel looks and why.

## Help by task

If you want to know _how_ to do something, start with your role:

- [I volunteer](/wichtel/en/helpers/) – signing up for shifts, swapping, points and goodies.
- [I lead an area](/wichtel/en/leads/) – planning shifts, staffing, check-in.
- [I run the festival](/wichtel/en/organizers/) – editions, areas, roles, rules, settings.
- [I run the server](/wichtel/en/operators/) – installation, configuration, updates and backups.
